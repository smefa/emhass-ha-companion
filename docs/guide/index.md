# User Guide

A plain walkthrough of every screen in EMHASS Companion — what each button
and field does, in order, with no explanation of *why* it works that way.

If you want the reasoning behind a setting, how the integration works
internally, or you're writing a profile or a PR, see the
**[Technical reference](../index.md)** instead — it covers the same ground
in much more depth.

## Pages in this guide

1. **[Install](install.md)** — getting the integration onto your system.
2. **[Setup](setup.md)** — the first-time wizard, step by step.
3. **[Deferrable loads](deferrable_loads.md)** — dishwashers, car chargers,
   anything whose *timing* can move.
4. **[Thermal loads](thermal_loads.md)** — heat pumps, heaters, anything
   whose *temperature* is controlled instead.
5. **[Surplus loads](surplus_loads.md)** — the extra sensors you get once a
   load runs only on spare solar.
6. **[Inverter control](inverter_control.md)** — letting the integration
   command your battery.
7. **[Hub controls](hub_controls.md)** — the switches, selects and sensors on
   the integration's own device.
8. **[Dashboard cards](dashboard_cards.md)** — the two cards that ship
   in-box.

Start with **Install** if you haven't added the integration yet.
